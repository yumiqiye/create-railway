# 机械动力：铁路增强（Create: Railway Plus，CRP）

## 简介

机械动力：铁路增强以中国铁路客运的真实流程为蓝本，在游戏内还原了从购票、支付、打印票据，到进站检票、闸机通行、退改签的完整闭环，并配套独立的网页购票站点、运营管理后台与车站引导显示系统。

模组同时对 Create、Create Railways Navigator（CRN）、Simurail 的可选兼容依赖，预留了车站、车次、列车位置与检票口状态的双向联动接口。

模组适用于希望在服务器内搭建完整铁路客运体系的玩家与服主，可用于高铁客运线路、城市地铁线路两类运营场景，并支持通过后台进行车次编排、票价核算、设备台账与乘车人管理。

## 核心功能

### 实名证件与票据体系

模组添加实名证件（身份证）作为乘车与购票的凭证。玩家在售票机前插入证件后，系统会读取证件信息并作为乘车人记录写入订单；购票完成后，售票机可打印实体车票、报销凭证与行程信息单，三类票据在关闭页面后对着购票机按 Shift+右键随证件一并取出。

票据类型包括：

- **车票**：进站检票与乘车的核心凭证，记录车次、席别、座位、乘车区间与乘车人信息；
- **报销凭证**：用于报销留底的纸质凭证，不可通过闸机检票；
- **行程信息单**：记录行程明细的辅助单据，不可通过闸机检票。

票据支持补打功能，可按 ticket、voucher、itinerary 三种类型分别补打车票、报销凭证与行程信息单，并记录补打次数。

### 售票机与网页购票

模组提供游戏内售票机（TVM）与网页购票站点两套购票入口。

游戏内售票机在安装 MCEF（mcef-NeoForge）后可直接在机器界面内渲染网页，展示车站可售车次、席别余票、发车与到达时间、票价与开检状态；售票机支持多乘客下单、票种选择、选座、往返票、退票与改签，票价由服务端按车站坐标与车次经停段自动计算，前端传入的票价不被信任。

网页购票站点为内嵌的 Node.js 服务，玩家可在浏览器中查询车次、选择席别与座位、填写乘车人信息并完成下单。订单创建时服务端会进行拦截校验：命中高铁或地铁黑名单的姓名与证件号禁止购票，单笔订单的乘客数量受系统设置 `maxPassengersPerOrder` 限制，同一订单内证件号不可重复。

### 闸机与检票规则

模组提供进站闸机、检票闸机与出站闸机三类设备，由后台登记设备台账并可远程配置欢迎语、摄像头与预览等参数，配置变更会递增 `configVersion` 并向客户端广播。

闸机通行规则如下：

- **进站闸机**：允许重复刷入，用于进站核验；
- **检票闸机**：单次通过，用于乘车检票；
- **出站闸机**：单次通过，用于出站核验。

行程信息单与报销凭证不能通过闸机检票。支付回调、票据打印状态回写、退票与改签均通过模组内部接口完成，请求需携带 `x-railway-token`，与后台 `railwayAdminToken` 保持一致。退票手续费由后端按规则计算，实际货币发放由模组在游戏内完成；改签时后端按新车次、日期与席别计算补退差额与改签手续费。

### 人工终端与车站引导屏

模组内置人工终端，供车站工作人员进行人工售票、退改签与票务查询。终端界面采用普通 Screen 实现，避免被 JEI 识别为容器界面而弹出物品与配方面板。

车站引导屏为方块实体显示设备，以方块局部坐标锚定屏面，支持 0.5–1.5 倍手动缩放，可在游戏内显示车次、发车时间、检票口、站台与余票等信息。引导屏同时可通过网页地址在浏览器中访问。

### 地铁模式与黑名单

模组内置地铁模式开关 `metroEnabled`，开启后可切换为城市地铁运营逻辑。乘车人黑名单分为高铁（highspeed）与地铁（metro）两个独立分桶，管理员可按姓名与证件号新增封禁记录；`minutes` 为 0 表示永久封禁，大于 0 表示按时长封禁，到期自动解除。黑名单在高铁下单时进行拦截校验。

网页端首次运行前需复制 `web/config.example.toml` 为 `web/config.toml`，并按需修改端口、令牌、二维码密钥与 hCaptcha 配置。模组内部写接口与后台管理接口分别通过 `x-railway-token` 与后台登录态进行鉴权，前台售票与查询接口无需令牌。

## 命令

模组提供 `/railway` 系列管理命令，包括车站划定、引导屏缩放调整等操作。车站名称支持带引号的字符串参数，可正常解析中文与带空格的站名，例如：

```mcfunction
/railway admin station "清江南站" POS1
/railway admin station "清江南站" POS2
```

对着准星所指的坐标划定车站范围。

```mcfunction
/railway admin screen scale <x y z> <0.5~1.5>
```

修改屏幕缩放。
